# 💰 FlowFinance AI

An AI-powered Expense Tracker that helps users manage their personal finances with smart insights, interactive analytics, and an intelligent AI assistant.

FlowFinance AI allows users to track income and expenses, visualize spending through charts, and receive personalized financial recommendations based on their transaction history.

---

## ✨ Features

### 🔐 Authentication
- User Registration & Login
- Secure JWT Authentication
- Protected Routes

### 💸 Transaction Management
- Add Transactions
- Update Transactions
- Delete Transactions
- View Transaction History
- Track Income & Expenses

### 📊 Analytics Dashboard
- 📈 Line Chart
- 📊 Bar Chart
- 🥧 Pie Chart

Visualize your financial data and spending patterns in an easy-to-understand dashboard.

### 🤖 AI Financial Assistant
The built-in AI assistant helps users by:

- Analyzing transaction history
- Providing personalized financial recommendations
- Identifying unnecessary spending
- Suggesting ways to save money
- Answering finance-related questions through chat

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Muhammad-Faizan-Marral/expense-tracker.git
```

### Install dependencies

Frontend

```bash
cd client
npm install
npm run dev
```

Backend

```bash
cd server
npm install
npx prisma generate
npm run dev
```
